# Scroll Car Animation

A scroll-driven car animation recreating the reference demo inspired by **ITZ FIZZ**.

## Live Demo
- [Live Webpage Demo](https://ais-pre-s33hv6d2fxw3qziq3v2xzn-886908213453.asia-southeast1.run.app)
- Reference: [https://paraschaturvedi.github.io/car-scroll-animation](https://paraschaturvedi.github.io/car-scroll-animation)

## Tech Stack
- HTML / CSS / JavaScript
- React 19 + TypeScript
- GSAP 3 + ScrollTrigger

## Features
- Pinned viewport track with `#d1d1d1` canvas background
- Centered 200px road track with `#1e1e1e` asphalt
- Top-view McLaren supercar moving along the track scrubbed to scroll position
- Dynamic green trail (`#45db7d`) expanding behind the car
- Letter-by-letter headline reveal: `W E L C O M E   I T Z F I Z Z`
- 4 Impact Metric Cards appearing at key scroll milestones:
  - `58% Increase in pick up point use`
  - `23% Decreased in customer phone calls`
  - `27% Increase in pick up point use`
  - `40% Decreased in customer phone calls`
